# The AutoStorage GUI

A browser GUI, started with `autostorage view`. For now it is a hello world: FastAPI sends a message and React shows it.

- **Back end:** [FastAPI](https://fastapi.tiangolo.com/), in `src/autostorage/gui/`: `app.py` (the `/api/...` routes) and `cli.py` (the `autostorage view` command).
- **Front end:** [Vite](https://vite.dev/) + [React](https://react.dev/) + [Tailwind CSS](https://tailwindcss.com/), in JavaScript, in `frontend/`. The app is `frontend/src/App.jsx`.

Pixi installs everything, Node.js included (the `gui` environment).

## Try it

```bash
pixi run gui-api   # build the page and serve it: open http://127.0.0.1:8765
```

FastAPI's interactive API docs are at http://127.0.0.1:8765/docs.

## Edit with live reload

Keep `gui-api` running, and in a second terminal:

```bash
pixi run gui-dev   # the Vite dev server: open http://localhost:5173
```

This page reloads as you edit `frontend/src/`, and Vite forwards `/api/...` requests to FastAPI.
After editing the Python code, restart `gui-api` (which also rebuilds the page at port 8765).

## How users run it

Users run `autostorage view` (`pixi run view` here). They need only Python: the built page ships inside the Python package (`autostorage[gui]`).
